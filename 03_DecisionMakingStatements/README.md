# Decision Making in C++

This folder contains programs based on decision-making statements in C++.

Decision-making allows a program to execute different blocks of code based on conditions.

## Topics Covered

- if statement
- if-else statement
- else-if ladder
- Nested conditions
- Comparison operators
- Relational operators

## Programs

- Largest of Two Numbers
- Smallest of Three Numbers
- Positive, Negative, or Zero
- Divisible by 3 and 5
- Voting Eligibility 
- Greatest Among Three Numbers
- Grade Calculator
- Leap Year Checker
- Uppercase or Lowercase Character 
- Triangle Type Checker 

## Key Learning

- Making decisions using conditions
- Comparing multiple values
- Using logical operators with conditions
- Building real-world decision systems
