# Day 4 — For Loops

This folder contains programs based on for loops.

Loops are used to repeat a block of code multiple times without writing the same statements repeatedly.

## Topics Covered

- for loop syntax
- Loop initialization
- Loop condition
- Loop increment/decrement
- Number patterns
- Mathematical operations using loops

## Programs

- Print Numbers from 1 to 100 
- Print Numbers from 100 to 1 
- Print Even Numbers Up to n 
- Print Odd Numbers Up to n 
- Print Multiples of 7 
- Numbers Divisible by 3 and 5 
- Print Squares from 1 to n 
- Print Cubes from 1 to n 
- Reverse Natural Numbers
- ASCII Values from A to Z 

## Key Learning

- Repeating tasks using loops
- Controlling loop execution
- Using loops with conditions
- Performing calculations efficiently
