# While & Do-While Loops in C++

This folder contains programs based on while loops and do-while loops in C++.

While and do-while loops are used to repeatedly execute a block of code based on a condition.

## Topics Covered

* while loop
* do-while loop
* Loop conditions
* Increment and decrement
* Digit manipulation
* Number manipulation

## Programs

* Print Numbers from 1 to n
* Print Even Numbers
* Print Odd Numbers
* Reverse a Number
* Count Digits
* Sum of Digits
* Product of Digits
* Find Largest Digit
* Find Smallest Digit
* Check if a Number is a Palindrome

## Key Learning

* Understanding while loops
* Understanding do-while loops
* Repeating operations using conditions
* Extracting digits using `%` and `/`
* Solving number-based problems
* Combining loops with conditional statements
