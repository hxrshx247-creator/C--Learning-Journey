# Functions in C++

This folder contains programs based on functions in C++.
Functions allow a program to divide a task into smaller, reusable blocks of code.

## Topics Covered

* Function declaration and definition
* Function parameters
* Function arguments
* Return values
* `void` functions
* Functions returning values
* `bool` functions
* Using functions with loops and conditions

## Programs

* Function to Print "Hello"
* Function to Add Two Numbers
* Function to Subtract Two Numbers
* Function to Multiply Two Numbers
* Function to Divide Two Numbers
* Function to Find the Square of a Number
* Function to Check Even or Odd
* Function to Find the Factorial
* Function to Check Prime
* Function to Find the Largest of Three Numbers

## Key Learning

* Understanding how functions work
* Passing values to functions
* Returning results from functions
* Reusing code instead of repeating it
* Combining functions with loops and conditions
* Building modular and organized programs
