# Day 9 — C++ Strings

This folder contains my Day 9 C++ practice programs focused on
strings and basic string manipulation.

## Topics Covered

- Creating and printing strings
- Taking string input using `cin` and `getline()`
- Finding string length using `length()` and `size()`
- Accessing individual characters using `at()` and `[]`
- Traversing strings using `for` loops
- Counting vowels
- Counting consonants
- Counting digits
- Reversing a string
- Checking whether a string is a palindrome
- Counting occurrences of a character
- Finding the frequency of characters
