# Day 8 – C++ Calculator Project 

This project is my first C++ mini-project, built after completing the fundamentals of C++ including variables, operators, decision-making statements, loops, functions, and arrays.

The calculator was developed in three versions, with each version improving the structure and functionality of the previous one.

##  Version 1 – Basic Calculator

### Features

* Addition
* Subtraction
* Multiplication
* Division
* Division-by-zero handling
* Invalid menu choice handling

### Concepts Practiced

* Variables
* `double` and `int`
* `cin` and `cout`
* Arithmetic operators
* `switch`
* `case`
* `break`
* `if-else`

## Version 2 – Repeating Calculator

Version 2 improves the original calculator by allowing the user to perform multiple calculations without restarting the program.

### Features

* All V1 operations
* Repeated calculations
* Exit option
* Division-by-zero handling
* Invalid choice handling

### Concepts Practiced

* `while` loops
* Loop conditions
* `if-else`
* `switch`
* Program flow
* User-controlled repetition

##  Version 3 – Function-Based Calculator

Version 3 reorganizes the calculator using separate functions for each operation.

### Functions Used

add()
subtract()
multiply()
divide()
showMenu()

### Concepts Practiced

* Function declarations
* Function definitions
* Function parameters
* Return values
* `void` functions
* Variable scope
* Calling functions
* Combining functions with `switch`
* Combining functions with loops

## Future Improvements
