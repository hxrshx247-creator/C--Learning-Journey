# Arrays – C++ Practice

This folder contains my practice programs for learning Arrays in C++ as part of my C++ and DSA learning journey.

I am focusing on understanding array fundamentals, traversal, indexing, basic calculations, and simple problem-solving before moving into more advanced DSA concepts.

## Topics Covered

- Array declaration and initialization
- Array indexing
- Accessing elements
- Forward traversal
- Reverse traversal
- Taking array input
- Finding the sum of elements
- Finding the average
- Finding the largest element
- Counting even and odd elements

## Programs

- Print all array elements 
- Access the first element 
- Access the last element 
- Traverse an array backwards 
- Access elements at even indexes 
- Take input and store it in an array 
- Calculate the sum of array elements 
- Calculate the average 
- Find the largest element 
- Count even and odd elements
