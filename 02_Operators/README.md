# C++ Operators

## Topics Covered

- Arithmetic operators
- Quotient and remainder
- Modulus operator (%)
- Even and odd numbers
- Square and cube
- Basic mathematical calculations
- Integer division
- Digit extraction

## Programs

1. Find quotient and remainder
2. Check whether a number is even or odd
3. Find square and cube of a number
4. Convert seconds into hours, minutes, and seconds
5. Calculate percentage
6. Find average of five numbers
7. Calculate electricity bill
8. Find last digit
9. Find last two digits
10. Find first digit of a three-digit number

## What I Learned

- `/` is used for division
- `%` gives the remainder
- `% 10` can be used to extract the last digit
- Integer division behaves differently from decimal division
